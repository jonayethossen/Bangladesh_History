#  Bangladesh Liberation War Digital Archive

A comprehensive digital repository dedicated to preserving the history, heroic testimonies, and significant documents of the 1971 Bangladesh Liberation War.

**Live Demo:** [https://bangladesh-history.netlify.app/](https://bangladesh-history.netlify.app/)

## 📖 Project Overview
This project is a tribute to the freedom fighters and martyrs of 1971. It serves as an educational platform where users can explore historical documents, listen to interviews with war veterans, and view curated photographs of the struggle for independence.

##  Key Features

### 1. Interactive Hero Section
- A visually engaging introduction to the significance of the 1971 war.
- Smooth navigation to different sections of the archive.

### 2. Historical Documents Catalog
- **Categorization:** Documents are organized by types such as Treaties, Declarations, and Correspondence.
- **Detailed View:** Each document includes a title, date, source, and description for academic and historical relevance.

### 3. Voices of Freedom (Interviews)
- **Biographical Details:** Structured presentation of freedom fighters' profiles (e.g., Adv. Fozlur Rahman Khan).
- **Media Access:** Integration for audio and video testimonies to provide an immersive experience.

### 4. Photograph Gallery
- A curated selection of high-resolution images capturing key moments and people.
- Responsive grid layout with hover effects and detailed captions.

### 5. Contribution & Contact System
- **Contribution Form:** A specialized form allowing users to submit feedback or contribute new materials (photos/documents) to the archive.
- **File Upload:** Integrated file input for community-driven historical preservation.

##  Tech Stack
- **Frontend:** React.js, Tailwind CSS
- **UI Components:** DaisyUI
- **Slider:** Swiper.js
- **Deployment:** Netlify
